数当てゲーム

数当てゲームのページ:数当てゲームはまずタイトルと予想回数を書くテキストボックスと予想用の文章を書き、また実行用のボタンを作りました。また、課題の指示通りに作るために、まずif文で数が当たっている時と当たっていない時に分けて当たっている時の表示を作りました。次にハズレの中から3回目に答えを表示する文章、それ以外の時に答えより予想が大きいか小さいかを表示する文章を作成しました。 この仕組みはボタンを押すと判定、また何回目の予想が出るかを出します。回数はボタンを出すたびに変数に＋１する仕組みにして作りました。この数当てを作るに当たってボタン内の処理が多いところが難しかったですが文章変更のtextContentやイッチするものを検索するquerySelectorを少し使い慣れることができました。 kazuate.html

各授業回の学習事項

第1回 WWWとHTML

WWWはWebページを提供する仕組みのこと、HTMLはWebページの構造を指定する記述であること。またどのようにHTMLを作って簡素なWebページの見た目を作成するか、重要な情報の目立たせ方や画像とリンクの貼り方を学びました。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Webページの装飾

cssは文字、背景、画像、色などのWebページのさまざまな情報を表現したり、わかりやすくする装飾の役割を持っていること、授業内でやったもの以外にも大量の種類があり、授業の資料のリンクの検索欄から全て覚えることはできなさそうな量の表現があることも知った。

演習の成果： 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

java Scriptのjavaとの違いにはコンパイルエラーが存在しないこと、エラーを出さないプログラムの作り方が一行ずつやってかなり違うことがわかった。また、追加することによって、表示のやり方に工夫を与えることができた。

演習の成果： 演習3-6: オブジェクトの参照

第4回 DOM と JavaScript

js側でどのような入力で文章を変更したり、どのようにイベントを作るのかを学べた。また基本的にはletで作り、検索をかけて変更する、また、ボタンを検索にかけ、ボタンにイベント登録をするとボタンを押すと実行されるという流れがわかりました。

演習の成果： 演習4-10: 足し算ページ
